# 🌐 Nexi Net Website

A modern and responsive business website developed for **Nexi Net**, a fiber internet service provider.

The website is designed to showcase internet plans, services, coverage information, and customer contact options through a clean and interactive user interface.

## ✨ Features

- 🌐 Internet service and plan information
- ⚡ Fiber broadband service showcase
- 📺 IPTV and OTT service information
- 📍 Coverage area information
- 📱 Responsive design for mobile and desktop
- 🎨 Modern user interface
- 📞 Customer contact and enquiry options
- 🚀 Deployed using Netlify

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Netlify
